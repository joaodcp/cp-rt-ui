# 🚆 comboios.live

A simple web application to check train realtime data in Portugal.

## Features

-   Real-time passenger train position information (Comboios de Portugal and Fertagus)
-   User-friendly interface
-   Mobile responsive design
-   Search by train, origin and destination

## Related projects
- [cp-gtfs-enhanced](https://github.com/joaodcp/cp-gtfs-enhanced) is a project that runs daily and adds multiple enhancements to CP's official GTFS feed. The enhanced feed introduces features such as trip shapes, planned platform numbers and international stations, which the official feed does not provide.
